## 01. 프로젝트 개요

### 1.1 문서 개요
- 정의하는 것: 사용자가 자기 운동 종목 목록을 부위별로 보고, 종목을 추가·수정·삭제하고, 부위 안 종목의 순서를 바꾸는 기능. 종목을 바꾸거나 지웠을 때 지난 기록에 생기는 일.
- 정의하지 않는 것:
  - 사용자·권한, 데이터, 공통 규칙, 비기능, 전체 범위, 초기 운동 목록 → `workout-common.md`
  - 종목을 골라 세션에 넣고 세트를 기록하는 기능 → `workout-exercise.md`
  - API 상세 설계, DB 스키마, 아키텍처, 기술 스택(→ 설계 문서에서 다룸)
- ID 규칙: workout-common 1.1을 따른다. 이 문서의 ID 위치는 workout-common 부록 B에 있다.
- 대상 독자: 백엔드 개발자, 모바일 클라이언트 개발자, 테스트 담당자, 기획자.

### 1.2 서비스 / 기능 개요
사용자마다 자기 종목 목록이 있다. 처음에는 서비스의 기본 목록(workout-common 부록 A)으로 시작하고, 이후 사용자가 종목을 더하거나 이름·부위를 고치거나 지우고, 부위 안에서 순서를 바꾼다. 운동 선택, 이전 기록 조회, 달력, 통계는 모두 이 목록을 쓴다.

| 기능 영역 | 설명 | 관련 요구사항 |
|----------|------|--------------|
| 종목 목록 보기 | 부위를 골라 그 부위의 종목과 종목 수를 본다. | REQ-EXERCISE-003 |
| 종목 추가 | 부위, 종목명, 영문명(선택)을 입력해 종목을 만든다. | REQ-EXERCISE-004 |
| 종목 수정 | 종목의 부위, 종목명, 영문명을 고친다. 지난 기록에도 반영된다. | REQ-EXERCISE-005 |
| 종목 삭제 | 확인한 뒤 종목을 지운다. 그 종목의 기록도 함께 지워진다. | REQ-EXERCISE-006 |
| 종목 순서 변경 | 한 부위 안에서 종목을 원하는 순서로 늘어놓는다. 운동 선택 화면도 그 순서를 따른다. | REQ-EXERCISE-007 |

### 1.3 외부 시스템 / 연동
해당 없음 — 종목에는 이미지가 없다(workout-common TODO-018).

## 02. 사용자 / 권한

| 기능 | 비로그인 | 일반 사용자 |
|------|---------|-----------|
| 종목 목록 조회 | ✕ | △ 본인 목록만 |
| 종목 추가 | ✕ | △ 본인 목록에만 |
| 종목 수정 / 삭제 | ✕ | △ 본인 목록의 종목만 |
| 종목 순서 변경 | ✕ | △ 본인 목록의 한 부위 안에서만 |

- 사용자는 자기 종목 목록만 보고 바꿀 수 있다. 다른 사용자의 종목은 존재 여부와 관계없이 볼 수 없고 바꿀 수 없다. (BR-022)
- 종목을 바꿔도 다른 사용자의 목록과 기록에는 아무 영향이 없다. (BR-022)
- 세션 상태와 관계없이 종목을 바꿀 수 있다. 진행 중인 세션이 있어도 된다.

## 03. 사용자 시나리오 / 화면 흐름

### 3.1 시나리오: 종목을 추가한다
```
[운동 선택 화면] (workout-exercise EX-001)
        ↓
사용자가 "종목 관리"를 누른다.
        ↓
[종목 관리 화면] (운동 선택에서 보던 부위가 골라져 있다)
        ↓
필요하면 다른 부위를 고른다.
        ↓
사용자가 "종목 추가"를 누른다.
        ↓
[종목 추가 화면] (종목 관리에서 고른 부위가 골라져 있다)
        ↓
부위를 고르고 종목명, 영문명(선택)을 입력한다.
   ├─ 추가 → 종목 생성 → [종목 관리 화면]
   └─ 취소 / 뒤로 → 저장하지 않음 → [종목 관리 화면]
```

### 3.2 시나리오: 종목을 고친다
```
[종목 관리 화면]
        ↓
사용자가 종목의 "수정"을 누른다.
        ↓
[종목 수정 화면] (지금 부위, 종목명, 영문명이 채워져 있다)
        ↓
값을 고친다.
   ├─ 저장 → 종목 수정. 지난 기록에도 새 값이 쓰인다 (BR-024) → [종목 관리 화면]
   └─ 취소 / 뒤로 → 저장하지 않음 → [종목 관리 화면]
```

### 3.3 시나리오: 종목을 지운다
```
[종목 관리 화면]
        ↓
사용자가 종목의 "삭제"를 누른다.
        ↓
[종목 삭제 확인 팝업] "<종목명>를 삭제할까요?"
   ├─ 삭제 → 종목과 그 종목의 모든 기록 삭제 (BR-025) → [종목 관리 화면]
   └─ 취소 → 지우지 않음 → [종목 관리 화면]
```

### 3.4 시나리오: 종목 순서를 바꾼다
```
[종목 관리 화면] (부위 하나가 골라져 있다)
        ↓
사용자가 종목의 위치를 옮긴다. ── 반복
        ↓
옮긴 순서를 저장한다. (BR-031, BR-032)
   ├─ 저장됨 → 새 순서로 보인다. [운동 선택 화면]도 같은 순서 → [종목 관리 화면]
   └─ 그 사이 다른 기기에서 그 부위의 종목이 바뀜 → 바꾸지 않고 다시 불러오라고 알림 (ERR-018) → 목록을 다시 불러와 다시 옮긴다
```
옮기는 방식(끌어서 옮기기, 위아래 버튼 등)과 저장 시점(옮길 때마다, 다 옮긴 뒤 한 번)은 디자인에서 정한다(8.2).

### 4.2 기능 상세

#### REQ-EXERCISE-003 종목 관리 목록 조회
- **목적:** 사용자가 부위별로 자기 종목을 보고, 고치거나 지울 종목을 고를 수 있어야 한다.
- **사전 조건:**
  - 로그인된 사용자여야 한다.
- **사용자 행동:**
  1. 운동 선택 화면에서 "종목 관리"를 누른다.
  2. 부위를 고른다.
- **입력:**
  - 부위 ID
- **처리 규칙:**
  - 이 사용자의 목록에서 고른 부위에 속한 종목만 가져온다. (BR-022)
  - 순서는 운동 선택 화면(EX-001)과 같다.
  - 고른 부위의 종목 수를 함께 알려준다.
- **결과:**
  - 고른 부위의 종목 목록과 종목 수를 받는다. 종목이 없으면 빈 목록이다.
- **예외:**
  - 로그인하지 않았으면 인증 오류를 반환한다. (ERR-001)
  - 존재하지 않는 부위이면 찾을 수 없음 오류를 반환한다. (ERR-009)
- **관련 화면:** EX-004

#### REQ-EXERCISE-004 종목 추가
- **목적:** 사용자가 기본 목록에 없는 운동을 자기 목록에 더해 기록할 수 있어야 한다.
- **사전 조건:**
  - 로그인된 사용자여야 한다.
- **사용자 행동:**
  1. 종목 관리 화면에서 "종목 추가"를 누른다.
  2. 부위를 고르고 종목명, 영문명(선택)을 입력한다.
  3. "추가"를 누른다.
- **입력:**
  - 부위 ID
  - 종목명
  - 영문명 (선택)
- **처리 규칙:**
  - 이 사용자의 목록에 종목을 만든다. 다른 사용자의 목록에는 생기지 않는다. (BR-022)
  - 부위와 종목명은 반드시 있어야 한다. 부위는 서비스가 제공하는 부위 중 하나여야 한다. (BR-023)
  - 종목명과 영문명의 앞뒤 공백은 지운다. 공백만 있는 종목명은 입력하지 않은 것으로 본다. (BR-023)
  - 종목명은 30자, 영문명은 50자까지다. (BR-023)
  - 같은 부위에 같은 종목명이 이미 있으면 추가하지 않는다. (BR-026)
  - 새 종목은 그 부위 목록의 맨 뒤에 둔다. (BR-027)
  - 새 종목은 타깃 설명이 없다. 운동 기록 화면(EX-002)에는 타깃 설명 없이 보인다. (BR-028)
- **결과:**
  - 종목이 생긴다. 바로 운동 선택 화면(EX-001)에서 고를 수 있다.
- **예외:**
  - 로그인하지 않았으면 인증 오류를 반환한다. (ERR-001)
  - 부위나 종목명이 없거나, 없는 부위이거나, 길이가 상한을 넘으면 저장하지 않는다. (ERR-016)
  - 같은 부위에 같은 종목명이 있으면 저장하지 않는다. (ERR-017)
- **관련 화면:** EX-005

#### REQ-EXERCISE-005 종목 수정
- **목적:** 사용자가 종목의 이름이나 부위를 자기에게 맞게 고칠 수 있어야 한다.
- **사전 조건:**
  - 로그인된 사용자여야 한다.
  - 고칠 종목이 본인 목록에 있어야 한다.
- **사용자 행동:**
  1. 종목 관리 화면에서 종목의 "수정"을 누른다.
  2. 부위, 종목명, 영문명을 고친다.
  3. "저장"을 누른다.
- **입력:**
  - 종목 ID
  - 부위 ID
  - 종목명
  - 영문명 (선택. 비우면 영문명을 지운다)
- **처리 규칙:**
  - 기본 목록에서 온 종목과 사용자가 추가한 종목을 똑같이 고칠 수 있다. (BR-022)
  - BR-023, BR-026을 똑같이 적용한다. 같은 이름인지 볼 때 고치는 종목 자신은 빼고, 부위를 바꾸면 새 부위에서 본다.
  - 고친 값은 그 종목의 지난 기록에도 쓰인다. 같은 종목으로 남는다. (BR-024)
    - 날짜별 기록, 오늘 한 운동, 이전 기록 조회, 최근 수행일은 이어진다.
    - 부위를 바꾸면 이 종목의 지난 볼륨·세트 수도 새 부위로 센다. 달력의 그날 부위 표시와 통계의 부위별 볼륨이 바뀐다.
  - 진행 중인 세션에 있는 종목이어도 고칠 수 있다. 기록한 세트는 그대로다.
  - 부위를 바꾸면 그 종목을 새 부위 목록의 맨 뒤에 두고(BR-027), 타깃 설명을 지운다(BR-028). 부위를 그대로 두면 순서와 타깃 설명도 그대로다.
- **결과:**
  - 종목이 새 값으로 저장된다.
- **예외:**
  - 로그인하지 않았으면 인증 오류를 반환한다. (ERR-001)
  - 다른 사용자의 종목이면 권한 오류를 반환한다. (ERR-003)
  - 종목이 없으면 찾을 수 없음 오류를 반환한다. (ERR-009)
  - 입력값이 규칙에 맞지 않으면 저장하지 않는다. (ERR-016)
  - 같은 부위에 같은 종목명이 있으면 저장하지 않는다. (ERR-017)
- **관련 화면:** EX-006

#### REQ-EXERCISE-006 종목 삭제
- **목적:** 사용자가 쓰지 않는 종목을 목록에서 없앨 수 있어야 한다.
- **사전 조건:**
  - 로그인된 사용자여야 한다.
  - 지울 종목이 본인 목록에 있어야 한다.
- **사용자 행동:**
  1. 종목 관리 화면에서 종목의 "삭제"를 누른다.
  2. 확인 팝업에서 "삭제"를 누른다.
- **입력:**
  - 종목 ID
- **처리 규칙:**
  - 사용자가 확인한 뒤에만 지운다.
  - 종목을 지우면 그 종목의 모든 기록도 지운다. 완료된 세션에 있는 기록도 지운다. BR-002의 예외다. (BR-025)
    - 진행 중인 세션에 있는 종목이면 세션에서도 빠진다. (REQ-EXERCISE-002와 같다)
    - 날짜별 기록, 달력, 이전 기록 조회, 최근 수행일, 통계에서 이 종목의 기록이 사라진다.
  - 그 결과 세트가 하나도 남지 않은 완료된 세션은 오운완 사진·동영상과 함께 지운다. 그날 다른 세션이 없으면 달력에서 그날이 사라진다. 진행 중인 세션은 세트가 없어도 그대로 둔다. (BR-029, workout-media BR-004)
  - 지운 종목과 기록은 되돌릴 수 없다. (workout-common 8.1 삭제 취소 제외)
  - 일부만 지워진 상태가 남지 않아야 한다. (NFR-AVAIL-001, NFR-INTEG-003)
  - 부위의 마지막 종목도 지울 수 있다. 빈 부위는 종목 추가로 다시 채운다. (BR-030)
- **결과:**
  - 종목과 그 종목의 기록이 사라진다. 운동 선택 화면에서 더는 고를 수 없다.
- **예외:**
  - 로그인하지 않았으면 인증 오류를 반환한다. (ERR-001)
  - 다른 사용자의 종목이면 권한 오류를 반환한다. (ERR-003)
  - 종목이 없거나 이미 지운 종목이면 찾을 수 없음 오류를 반환한다. (ERR-009)
- **관련 화면:** EX-004

#### REQ-EXERCISE-007 종목 순서 변경
- **목적:** 사용자가 한 부위의 종목을 자기가 하는 순서대로 늘어놓아, 운동 선택 화면에서 원하는 종목을 빨리 찾을 수 있어야 한다.
- **사전 조건:**
  - 로그인된 사용자여야 한다.
  - 고른 부위에 본인 종목이 있어야 한다.
- **사용자 행동:**
  1. 종목 관리 화면에서 부위를 고른다.
  2. 종목의 위치를 옮긴다.
  3. 옮긴 순서를 저장한다.
- **입력:**
  - 부위 ID
  - 그 부위 종목의 새 순서 (종목 ID를 원하는 순서대로 나열한 것)
- **처리 규칙:**
  - 한 부위 안에서만 순서를 바꾼다. 종목을 다른 부위로 옮기는 것은 종목 수정(REQ-EXERCISE-005)으로 한다. (BR-031)
  - 새 순서에는 그 부위의 본인 종목이 빠짐없이 한 번씩 있어야 한다. 그렇지 않으면 바꾸지 않는다. (BR-032, ERR-018)
  - 저장한 순서는 운동 선택(EX-001), 종목 관리(EX-004), 통계의 종목 목록에 똑같이 쓰인다. (BR-031)
  - 순서만 바뀐다. 종목의 이름·부위와 지난 기록은 그대로다.
  - 순서를 바꾼 뒤에 추가하거나 다른 부위에서 옮겨 온 종목은 맨 뒤에 온다. (BR-027)
  - 순서를 바꾸는 사이 다른 기기에서 그 부위의 종목이 추가·삭제·이동됐으면, 새 순서가 지금 목록과 맞지 않으므로 바꾸지 않는다. 일부만 반영하지 않는다. (BR-032, ERR-018)
- **결과:**
  - 그 부위의 종목이 새 순서로 보인다.
- **예외:**
  - 로그인하지 않았으면 인증 오류를 반환한다. (ERR-001)
  - 새 순서가 그 부위의 본인 종목과 맞지 않으면(빠진 종목, 두 번 나온 종목, 그 부위에 없는 종목·다른 사용자의 종목, 없는 부위) 바꾸지 않고, 목록이 바뀌었으니 다시 불러와 옮겨 달라고 알린다. (ERR-018)
- **관련 화면:** EX-004

## 06. 비즈니스 규칙 / 예외

### 6.1 비즈니스 규칙
공통 규칙(BR-001, 002, 009, 010, 015)은 workout-common 6.1에 있다. BR-022는 여러 문서에 걸려 workout-common 6.1에 둔다.

- **BR-022** (workout-common) 운동 종목 목록은 사용자마다 따로 있다.
- **BR-023** 종목에는 부위와 종목명이 반드시 있어야 하고, 영문명은 선택이다. 부위는 서비스가 제공하는 부위 중 하나다. 종목명·영문명의 앞뒤 공백은 지우고, 공백만 있는 종목명은 입력하지 않은 것으로 본다. 종목명은 30자, 영문명은 50자까지다.
- **BR-024** 종목의 부위·종목명·영문명을 고치면 그 종목의 지난 기록에도 새 값이 쓰인다. 부위를 바꾸면 지난 볼륨·세트 수도 새 부위로 센다.
- **BR-025** 종목을 지우면 그 종목을 가리키는 모든 세션 내 운동과 세트를 함께 지운다. 완료된 세션도 포함한다(BR-002의 예외). 사용자가 확인한 뒤에만 지운다.
- **BR-026** 한 사용자의 같은 부위 안에서는 종목명이 겹칠 수 없다. 앞뒤 공백을 지운 뒤 대소문자를 구분하지 않고 비교한다. 다른 부위라면 같은 이름을 쓸 수 있다.
- **BR-027** 새로 추가한 종목과 부위를 바꾼 종목은 그 부위 목록의 맨 뒤에 둔다.
- **BR-028** 타깃 설명은 기본 목록에서 온 종목에만 있다. 사용자가 추가한 종목에는 없고, 부위를 바꾼 종목은 타깃 설명을 지운다. 사용자는 타깃 설명을 입력하거나 고칠 수 없다.
- **BR-029** 종목을 지워 세트가 하나도 남지 않은 완료된 세션은 함께 지운다(사진·동영상 포함). 진행 중인 세션은 세트가 없어도 지우지 않는다.
- **BR-030** 부위의 마지막 종목도 지울 수 있다. 종목이 없는 부위는 운동 선택(EX-001)과 종목 관리(EX-004)에서 빈 상태로 보여준다.
- **BR-031** 종목의 순서는 부위마다 사용자가 정한다. 순서는 한 부위 안에서만 바꾸고, 운동 선택(EX-001)·종목 관리(EX-004)·통계의 종목 목록이 모두 같은 순서를 쓴다. 처음 순서는 기본 목록(workout-common 부록 A)의 순서다.
- **BR-032** 순서를 바꿀 때 새 순서에는 그 부위의 본인 종목이 빠짐없이, 한 번씩만 들어 있어야 한다.

## 08. 범위 / 제약 / 미결정 사항

### 8.1 범위
- **포함:**
  - 부위별 본인 종목 목록과 종목 수 보기
  - 종목 추가 (부위, 종목명, 영문명)
  - 종목 수정 (부위, 종목명, 영문명). 기본 목록에서 온 종목 포함
  - 종목 삭제와 그 종목의 기록 삭제
  - 한 부위 안 종목 순서 바꾸기
- **제외:** (요청이 있기 전까지 만들지 않는다)
  - 부위의 순서 바꾸기 (부위 순서는 서비스가 정한다)
  - 기본 순서로 되돌리기, 이름순 등 자동 정렬
  - 타깃 설명 입력·수정 (BR-028)
  - 부위 추가·수정·삭제 (부위는 가슴, 등, 어깨, 하체 4개로 고정)
  - 기본 목록으로 되돌리기, 지운 기본 종목 다시 받기
  - 서비스가 기본 목록을 바꿨을 때 이미 있는 사용자 목록에 반영하기
  - 종목을 다른 사용자와 공유하기
  - 두 종목을 하나로 합치기
  - 종목 삭제 취소(undo), 휴지통 (workout-common 8.1)
  - 종목 검색 (workout-common 8.1)

### 8.2 제약사항
- workout-common 8.2를 따른다.
- 이미 기록이 있는 사용자도 기본 목록을 받아야 하고, 그 사용자의 지난 기록은 받은 목록의 같은 종목으로 이어져야 한다. 기록, 이전 기록 조회, 최근 수행일, 통계가 이 변경 전과 같아야 한다.
- 이 변경으로 다른 문서에서 바뀌는 것:
  - workout-common: BR-009, BR-022, DATA-002, NFR-INTEG-003, NFR-LOG-001, 2.2, 8.1, TODO-002 (이번에 함께 고쳤다)
  - workout-exercise: EX-001에 "종목 관리" 진입 추가, 종목 목록이 본인 목록 (이번에 함께 고쳤다)
  - workout-stats: REQ-STATS-003·BR-017의 종목 순서를 본인 목록 순서로, 8.2의 종목 출처를 본인 목록으로 (이번에 함께 고쳤다)
- 디자인에 추가하거나 바꿔야 할 것:
  - 종목 삭제 확인 팝업 문구가 "가슴 종목 목록에서 제외돼요"뿐이다. 그 종목의 지난 기록과 통계도 함께 지워지고 되돌릴 수 없다는 안내가 필요하다. (BR-025)
  - 종목이 없는 부위의 빈 상태가 운동 선택 화면과 종목 관리 화면에 없다. (BR-030)
  - 같은 이름이 있을 때(ERR-017)와 입력이 너무 길 때(ERR-016) 보여줄 안내가 종목 추가·수정 화면에 없다.
  - 종목 순서를 바꾸는 방법이 디자인에 없다. 옮기는 방식(끌어서 옮기기, 위아래 버튼 등)과 저장 시점(옮길 때마다, 다 옮긴 뒤 한 번), 순서 변경에 실패했을 때의 안내를 정해야 한다. (REQ-EXERCISE-007, ERR-018)
  - 종목 관리 화면의 하단 탭이 "홈"으로 표시된다. 운동 선택 화면에서 들어오므로 문제는 없지만, 다른 진입점이 필요하면 디자인에서 정한다.
