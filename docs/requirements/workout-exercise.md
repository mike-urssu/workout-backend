## 01. 프로젝트 개요

### 1.1 문서 개요
- 정의하는 것: 부위의 종목 목록에서 종목을 골라 세션에 넣고, 종목마다 세트(중량, 반복 횟수)를 기록·수정·삭제하고, 이 종목의 지난 기록을 보고, 오늘 한 운동을 보는 기능.
- 정의하지 않는 것:
  - 사용자·권한, 데이터, 공통 규칙, 비기능, 전체 범위, 초기 운동 목록 → `workout-common.md`
  - 운동 시작·완료·취소와 진행 현황 조회 → `workout-session.md`
  - 지난 기록 달력 → `workout-history.md`
  - API 상세 설계, DB 스키마, 아키텍처, 기술 스택(→ 설계 문서에서 다룸)
- ID 규칙: 운동 기록 문서 다섯 개는 ID 번호를 함께 쓴다. 같은 번호가 두 문서에 있지 않으므로 묶음 안에서는 ID만 쓰고, 어느 문서에 있는지는 `workout-common.md` 부록 B(ID 색인)에서 찾는다. 다른 문서(auth, workout-media, workout-stats)의 ID는 문서 이름을 붙여 쓴다(예: workout-media REQ-MEDIA-001).
- 대상 독자: 백엔드 개발자, 모바일 클라이언트 개발자, 테스트 담당자, 기획자.

### 1.2 서비스 / 기능 개요
사용자는 부위를 골라 종목을 고르고, 그 종목에서 한 세트를 하나씩 기록한다. 기록하면서 같은 종목의 지난 기록을 세션 하나씩 넘겨 볼 수 있다.

| 기능 영역 | 설명 | 관련 요구사항 |
|----------|------|--------------|
| 세션 내 운동 관리 | 진행 중인 세션에 수행할 운동을 추가하거나 뺀다. | REQ-EXERCISE-001, REQ-EXERCISE-002 |
| 세트 기록 | 운동별로 세트의 중량과 반복 횟수를 기록하고, 고치고, 지운다. | REQ-SET-001 ~ REQ-SET-003 |
| 이전 기록 조회 | 기록 중인 종목의 지난 기록(수행 날짜와 세트)을 세션 하나씩 좌우로 넘겨 본다. | REQ-SET-006 |

### 1.3 외부 시스템 / 연동
해당 없음 — 부위 이미지는 workout-common 1.3을 따른다. 종목 이미지는 두지 않는다(TODO-018).

## 02. 사용자 / 권한
workout-common 2장을 따른다. 운동 목록 조회는 로그인한 사용자 누구나 할 수 있고, 종목·세트 변경은 본인의 진행 중인 세션에만 할 수 있다. 이전 기록 조회는 본인 기록만 볼 수 있다.

## 03. 사용자 시나리오 / 화면 흐름

화면 흐름과 화면 정의는 Figma 디자인을 따른다(workout-common 8.2). 시작부터 완료까지의 전체 흐름은 workout-common 3.1에 있다.

### 3.1 시나리오: 종목을 골라 세트를 기록한다
```
[홈 화면] (workout-session)
        ↓
사용자가 부위(가슴, 등, 어깨, 하체)를 고른다.
        ↓
[운동 선택 화면] (고른 부위의 종목 목록)
        ↓
사용자가 종목을 고른다. 진행 중인 세션이 없으면 세션을 자동으로 시작한다(BR-019). 세션에 없는 종목이면 세션에 추가한다.
        ↓
[운동 기록 화면] (고른 종목 하나)
        ↓
세트 추가 (중량, 반복 횟수 입력) ── 반복
필요하면 [이전 기록] 보기, [오늘 한 운동] 보기
        ↓
다른 종목을 하려면 [운동 선택 화면]이나 [홈 화면]으로 돌아간다.
```

### 3.2 화면 정의

  - 로그인 완료

  - 종목 선택
  - 종목 관리 (EX-004, workout-exercise-manage)
  - 홈으로 돌아가기
- 시스템 동작:
  - 고른 부위에 있는 본인 목록의 종목을 목록 순서대로 조회한다. (BR-022)
  - 종목마다 이 사용자가 마지막으로 수행한 날을 조회한다. 완료된 세션에서 그 종목의 세트를 1개 이상 기록한 날만 수행한 날로 센다. 세트 없이 추가만 한 종목은 수행하지 않은 것이다.

  - 부위명
  - 종목 ID, 종목명, 영문 종목명

  - 고른 부위에 종목이 없을 때의 빈 상태 (BR-030)
  - 종목 이미지와 운동 검색은 없다(TODO-018, TODO-017 결정).
- 다음 화면:
  - 운동 기록 화면 (EX-002)
  - 종목 관리 (EX-004)

### 4.2 기능 상세

#### REQ-EXERCISE-001 세션에 운동 추가
- **목적:** 사용자가 이번 운동에서 수행하는 운동 종목을 세션에 추가할 수 있어야 한다.
- **사전 조건:**
  - 로그인된 사용자여야 한다.
  - 본인의 진행 중인 세션이 있어야 한다. 없으면 세션을 자동으로 시작한 뒤 추가한다. (BR-019)
  - 선택한 운동이 서비스가 제공하는 운동 목록에 있어야 한다. (BR-009)
- **사용자 행동:**
  1. 홈에서 부위를 고른다.
  2. 운동 선택 화면에서 종목을 고른다.
- **입력:**
  - 세션 ID
  - 운동 ID
- **처리 규칙:**
  - 선택한 운동을 세션에 추가한다.
  - 세션 안에서 운동의 순서는 추가한 순서대로 유지한다.
  - 이미 세션에 있는 종목을 고르면 다시 추가하지 않고, 그 종목의 운동 기록 화면으로 간다.
  - 진행 중인 세션이 없으면 REQ-WORKOUT-001과 같은 규칙으로 세션을 시작한 뒤 종목을 추가한다. (BR-019)
- **결과:**
  - 세션에 운동이 추가되고, 세트가 없는 상태로 운동 기록 화면에 나타난다.
- **예외:**
  - 로그인하지 않았으면 인증 오류를 반환한다. (ERR-001)
  - 존재하지 않는 운동이면 추가할 수 없다. (ERR-002)
  - 다른 사용자의 세션이면 권한 오류를 반환한다. (ERR-003)
  - 완료된 세션이면 추가할 수 없다. (ERR-007)
- **관련 화면:** EX-001, EX-002

#### REQ-EXERCISE-002 세션에서 운동 삭제
- **목적:** 사용자가 잘못 추가한 운동을 세션에서 뺄 수 있어야 한다.
- **사전 조건:**
  - 로그인된 사용자여야 한다.
  - 본인의 진행 중인 세션에 해당 운동이 있어야 한다.
- **사용자 행동:**
  1. 운동 기록 화면에서 운동 삭제를 누른다.
- **입력:**
  - 세션 ID
  - 세션 내 운동 ID
- **처리 규칙:**
  - 세션에서 운동을 삭제한다.
  - 그 운동에 기록된 세트도 함께 삭제한다. (NFR-INTEG-002)
- **결과:**
  - 세션에서 운동과 그 세트가 사라진다.
- **예외:**
  - 로그인하지 않았으면 인증 오류를 반환한다. (ERR-001)
  - 다른 사용자의 세션이면 권한 오류를 반환한다. (ERR-003)
  - 완료된 세션이면 삭제할 수 없다. (ERR-007)
  - 해당 운동이 세션에 없으면 찾을 수 없음 오류를 반환한다. (ERR-009)
- **관련 화면:** EX-002

#### REQ-SET-001 세트 기록 추가
- **목적:** 사용자가 운동마다 수행한 세트를 기록할 수 있어야 한다.
- **사전 조건:**
  - 로그인된 사용자여야 한다.
  - 본인의 진행 중인 세션에 해당 운동이 있어야 한다.
- **사용자 행동:**
  1. 운동 기록 화면에서 세트 추가를 누른다.
  2. 중량과 반복 횟수를 입력한다.
- **입력:**
  - 세션 내 운동 ID
  - 중량
  - 반복 횟수
- **처리 규칙:**
  - 해당 운동의 마지막 세트 다음 번호로 세트를 저장한다.
  - 세트를 추가한 시각을 기록한다. (REQ-WORKOUT-006에서 종료 시각으로 쓴다)
  - 반복 횟수는 1 이상 1,000 이하의 정수여야 한다. (BR-003)
  - 중량은 kg 단위, 0 이상 1,000 이하, 소수점 둘째 자리까지여야 한다. (BR-005)
- **결과:**
  - 세트가 생성된다.
- **예외:**
  - 로그인하지 않았으면 인증 오류를 반환한다. (ERR-001)
  - 다른 사용자의 세션이면 권한 오류를 반환한다. (ERR-003)
  - 입력값이 규칙에 맞지 않으면 저장하지 않는다. (ERR-005)
  - 완료된 세션이면 추가할 수 없다. (ERR-007)
  - 해당 운동이 없으면 찾을 수 없음 오류를 반환한다. (ERR-009)
  - 필수 입력이 빠졌으면 저장하지 않는다. (ERR-010)
- **관련 화면:** EX-002

- **사용자 행동:**

  2. 값을 바꾸고 저장한다.
- **입력:**

  - 중량
  - 반복 횟수
- **처리 규칙:**

  - 세트 번호와 세트를 추가한 시각은 바뀌지 않는다.
  - BR-003, BR-005를 똑같이 적용한다.
- **결과:**
  - 세트가 새 값으로 저장된다.
- **예외:**

  - 다른 사용자의 세트이면 권한 오류를 반환한다. (ERR-003)
  - 입력값이 규칙에 맞지 않으면 저장하지 않는다. (ERR-005)

#### REQ-SET-006 이전 기록 조회
- **목적:** 사용자가 세트를 기록하는 동안 같은 종목의 지난 기록을 보고 이번 중량·반복 횟수를 정할 수 있어야 한다.
- **사전 조건:**
  - 로그인된 사용자여야 한다.
  - 본인 목록의 종목이어야 한다. (BR-022)
  - 이 종목을 기록한 완료된 세션이 있어야 한다. 없으면 볼 기록이 없다. (ERR-013)
- **사용자 행동:**
  1. 운동 기록 화면에서 "이전 기록"을 누른다.
  2. 팝업에서 가장 최근 기록을 본다.
  3. 좌우로 넘겨 더 이전 기록이나 더 이후 기록을 본다.
  4. 팝업을 닫는다.
- **입력:**
  - 운동 ID
  - 지금 보고 있는 기록에서 어느 쪽(이전 / 이후)으로 넘기는지 (처음 열 때는 없음)
- **처리 규칙:**
  - 본인의 기록만 보여준다. (BR-001)
  - 이 종목의 세트를 1개 이상 기록한 완료된 세션만 대상이다. 진행 중인 세션(지금 기록 중인 세션 포함)은 대상이 아니다. (BR-016)
  - 한 번에 세션 하나를 보여준다. 처음에는 가장 최근 세션을 보여주고, 넘기면 수행 순서상 바로 이전 또는 이후의 세션을 보여준다. 같은 날 세션이 여러 개면 각각 따로 보여준다.
  - 세션마다 수행 날짜와 그 세션에서 이 종목의 세트를 세트 번호 순으로 보여준다. 다른 종목의 세트는 보여주지 않는다.
  - 더 이전 기록, 더 이후 기록이 있는지 함께 알려준다.
  - 보기만 한다. 이번 세션의 세트는 바뀌지 않는다.
- **결과:**
  - 이전 기록 한 건(수행 날짜, 세트)과 앞뒤로 더 넘길 기록이 있는지를 받는다.
- **예외:**
  - 로그인하지 않았으면 인증 오류를 반환한다. (ERR-001)
  - 다른 사용자의 종목이면 권한 오류를 반환한다. (ERR-003)
  - 종목이 없으면 찾을 수 없음 오류를 반환한다. (ERR-009)
  - 이 종목을 기록한 완료된 세션이 없으면 이전 기록이 없다고 알린다. (ERR-013)
- **관련 화면:** EX-002, EX-007
