## 01. 프로젝트 개요

### 1.1 문서 개요
- 정의하는 것: Let's Workout 서비스 **운동 기록 기능** 전체에 공통인 내용(사용자와 권한, 전체 화면 흐름, 관리할 데이터, 공통 규칙과 예외, 비기능 요구, 범위, 결정 이력, 초기 운동 목록).
- 정의하지 않는 것:
  - 화면별 기능 요구사항 → `workout-session.md`(홈·운동 진행), `workout-exercise.md`(운동 선택·세트 기록), `workout-history.md`(운동 기록 달력), `workout-exercise-manage.md`(운동 종목 관리)
  - 통계(`workout-stats.md`), 오운완 인증 사진/동영상(`workout-media.md`), 로그인·로그아웃(`auth.md`), 프로필 기능
  - API 상세 설계, DB 스키마, 아키텍처, 기술 스택(→ 설계 문서에서 다룸)
- ID 규칙: 운동 기록 문서 다섯 개는 ID 번호를 함께 쓴다. 같은 번호가 두 문서에 있지 않으므로 묶음 안에서는 ID만 쓰고, 어느 문서에 있는지는 `workout-common.md` 부록 B(ID 색인)에서 찾는다. 다른 문서(auth, workout-media, workout-stats)의 ID는 문서 이름을 붙여 쓴다(예: workout-media REQ-MEDIA-001).
- 대상 독자: 백엔드 개발자, 모바일 클라이언트 개발자, 테스트 담당자, 기획자.

### 1.2 서비스 / 기능 개요
운동 기록 기능은 사용자가 운동을 시작해서 끝낼 때까지 무엇을 몇 세트, 몇 회, 몇 kg으로 했는지 남기고, 나중에 지난 기록을 다시 볼 수 있게 한다. 기록 단위는 "운동 세션(한 번의 운동) → 세션 안의 운동 → 운동별 세트"이다.

| 기능 영역 | 설명 | 관련 요구사항 | 문서 |
|----------|------|--------------|------|
| 운동 세션 진행 | 운동을 시작하고, 끝나면 완료 처리해 기록으로 확정한다. 그만두려면 취소한다. 완료를 잊은 세션은 시스템이 정리한다. | REQ-WORKOUT-001, REQ-WORKOUT-002, REQ-WORKOUT-006, REQ-WORKOUT-010 | workout-session |
| 진행 중인 운동 현황 | 운동하는 동안 지금까지 한 종목·세트·볼륨을 홈, 오늘 한 운동, 운동 완료 팝업에서 본다. | REQ-WORKOUT-009 | workout-session |
| 세션 내 운동 관리 | 진행 중인 세션에 수행할 운동을 추가하거나 뺀다. | REQ-EXERCISE-001, REQ-EXERCISE-002 | workout-exercise |
| 세트 기록 | 운동별로 세트의 중량과 반복 횟수를 기록하고, 고치고, 지운다. 기록하면서 같은 종목의 지난 기록을 세션 하나씩 넘겨 본다. | REQ-SET-001 ~ REQ-SET-003, REQ-SET-006 | workout-exercise |
| 지난 기록 조회 / 삭제 | 월 달력에서 운동한 날과 부위를 보고, 날짜를 골라 그날 기록을 보고, 필요 없는 기록을 삭제한다. | REQ-WORKOUT-005, REQ-WORKOUT-007, REQ-WORKOUT-008 | workout-history |
| 운동 종목 관리 | 사용자가 자기 종목 목록에 종목을 추가하고, 고치고, 지우고, 부위 안에서 순서를 바꾼다. 지우면 그 종목의 기록도 지워진다. | REQ-EXERCISE-003 ~ REQ-EXERCISE-007 | workout-exercise-manage |

### 1.3 외부 시스템 / 연동
- 부위 이미지와 같은 파일 데이터를 저장하고 조회할 수 있어야 한다. (어디에 저장할지는 설계 단계에서 정한다)
- 사용자가 직접 올리는 오운완 인증 사진/동영상은 `workout-media.md`에서 다룬다.

## 02. 사용자 / 권한

### 2.1 사용자 유형
| 사용자 유형 | 설명 |
|------------|------|
| 비로그인 사용자 | 로그인하지 않은 사용자. 운동 기록 기능을 쓸 수 없다. |
| 일반 사용자 | 로그인한 사용자. 자신의 운동 기록을 만들고, 보고, 고치고, 지운다. |
| 관리자 | 해당 없음 — 관리자 기능은 범위 밖이다(8.1). |
| 시스템 | 사람이 아닌 서비스 자신. 방치된 세션을 정리하는 일만 한다(REQ-WORKOUT-006). |

### 2.2 권한 규칙
| 기능 | 비로그인 | 일반 사용자 |
|------|---------|-----------|
| 운동 목록 조회 | ✕ | △ 본인 목록만 |
| 운동 종목 추가 / 수정 / 삭제 / 순서 변경 | ✕ | △ 본인 목록의 종목만 (세션 상태와 무관, 순서는 한 부위 안에서) |
| 운동 세션 시작 | ✕ | ○ |
| 세션에 운동 추가 / 삭제 | ✕ | △ 본인 세션 + 진행 중 상태만 |
| 세트 추가 / 수정 / 삭제 | ✕ | △ 본인 세션 + 진행 중 상태만 |
| 운동 세션 완료 | ✕ | △ 본인 세션 + 진행 중 상태만 |
| 이전 기록 조회 | ✕ | △ 본인 기록만 |
| 운동 달력 / 날짜별 기록 조회 | ✕ | △ 본인 기록만 |
| 운동 기록 삭제 (날짜 단위) | ✕ | △ 본인 기록만 |
| 진행 중인 운동 취소 | ✕ | △ 본인 세션 + 진행 중 상태만 |

- 일반 사용자는 자신의 운동 기록만 조회·수정·삭제할 수 있다. 다른 사용자의 기록은 존재 여부와 관계없이 볼 수 없다. (BR-001)
- 운동·세트를 추가·수정·삭제할 수 있는 것은 진행 중인 세션뿐이다. 완료된 세션은 고칠 수 없고, 잘못 기록했으면 삭제한 뒤 다시 기록한다. (BR-002)
- 완료된 기록은 날짜 단위로 삭제하고(BR-020), 진행 중인 세션은 운동 취소로 지운다(REQ-WORKOUT-010).
- 운동 종목 목록은 사용자마다 따로 있다. 사용자는 자기 목록만 보고 바꿀 수 있다. (BR-022) 종목을 지우면 완료된 세션에 있는 그 종목의 기록도 지워진다(BR-002의 예외, BR-025).

### 3.1 시나리오: 운동을 시작해서 기록을 남긴다 (전체 흐름)
여러 문서에 걸친 흐름이다. 홈·운동 완료는 workout-session, 운동 선택·기록은 workout-exercise가 정의한다.
```
[홈 화면]
        ↓
사용자가 운동 시작을 누른다. 운동 시작 없이 부위와 종목부터 고르면 종목을 고를 때 세션을 자동으로 시작한다. (BR-019)
        ↓
운동 세션 생성 (진행 중)
        ↓
사용자가 부위(가슴, 등, 어깨, 하체 등)를 고른다.
        ↓
[운동 선택 화면] (고른 부위의 종목 목록)
        ↓
사용자가 종목을 고른다. 세션에 없는 종목이면 세션에 추가한다.
        ↓
[운동 기록 화면] (고른 종목 하나)
        ↓
세트 추가 (중량, 반복 횟수 입력) ── 반복
필요하면 [이전 기록] 보기, [오늘 한 운동] 보기
        ↓
다른 종목을 하려면 [운동 선택 화면]이나 [홈 화면]으로 돌아간다.
        ↓
[홈 화면]에서 운동 종료를 누른다. (운동을 그만두려면 운동 취소 → 확인 → 세션과 기록한 세트를 지운다)
        ↓
[운동 완료 팝업] 이번 운동 요약 확인, 오운완 인증 사진·동영상 첨부 (workout-media)
   ├─ 저장하기 → 첨부한 사진·동영상과 함께 세션 완료 → [홈 화면]
   ├─ 건너뛰기 → 사진·동영상 없이 세션 완료 → [홈 화면]
   └─ 팝업 닫기 → 완료하지 않고 운동을 이어간다 → [홈 화면]
```

## 05. 데이터 요구사항

#### DATA-001 운동 세션(운동 기록)
- 설명: 사용자가 한 번 운동한 단위. "운동 기록"이라고도 부른다.
- 관리해야 하는 정보: 기록한 사용자, 수행 날짜, 시작 시각, 종료 시각, 상태(진행 중 / 완료)
- 관계: 한 명의 사용자에 속한다. 0개 이상의 세션 내 운동을 가진다. 0개 이상의 오운완 인증 사진·동영상을 가진다(workout-media DATA-001).
- 생명주기: 운동 시작 시 "진행 중"으로 생성 → 사용자가 완료하거나, 6시간이 지나 자동으로 완료·삭제(BR-013) → 완료되면 이후 수정 불가 → 사용자 요청 시 완전히 삭제(보관하지 않음, TODO-001 결정). 종목을 지워 세트가 하나도 남지 않은 완료된 세션도 함께 삭제(BR-029). 운영자가 계정을 삭제하면 그 사용자의 운동 기록도 모두 함께 삭제(auth BR-012)
- 관련 규칙: BR-001, BR-002, BR-004, BR-008

#### DATA-002 운동(종목)
- 설명: 벤치프레스, 스쿼트처럼 사용자가 수행하는 운동의 종류
- 관리해야 하는 정보: 소유 사용자, 운동명, 영문 운동명(선택), 카테고리(부위, DATA-006), 타깃 설명(기본 목록에서 온 종목만, 부위를 바꾸면 지움, BR-028, 예: 가슴 중부 타겟), 카테고리 안에서의 순서(사용자가 바꿀 수 있다, BR-031) (종목 이미지는 두지 않는다, TODO-018)
- 관계: 한 명의 사용자에 속한다. 하나의 카테고리에 속한다. 그 사용자의 여러 세션 내 운동에서 참조된다.
- 생명주기: 사용자마다 기본 목록(부록 A)으로 생성 → 사용자가 추가·수정·삭제하고 부위 안 순서를 바꿈(workout-exercise-manage) → 지우면 그 종목을 가리키는 세션 내 운동과 세트도 함께 지운다(BR-025). 계정을 삭제하면 그 사용자의 종목도 함께 삭제. 고치면 지난 기록에도 새 값이 쓰인다(BR-024).
- 관련 규칙: BR-009, BR-022 ~ BR-028, BR-031, BR-032

#### DATA-003 세션 내 운동
- 설명: 특정 세션에서 수행한 운동 하나
- 관리해야 하는 정보: 소속 세션, 운동(종목), 세션 안에서의 순서
- 관계: 하나의 세션에 속한다. 하나의 운동(종목)을 가리킨다. 0개 이상의 세트를 가진다.
- 생명주기: 진행 중인 세션에 추가 시 생성 → 진행 중에만 삭제 가능 → 세션이 삭제되면 함께 삭제
- 관련 규칙: BR-002

#### DATA-004 세트
- 설명: 세션 내 운동에서 수행한 한 세트
- 관리해야 하는 정보: 세트 번호, 중량(kg), 반복 횟수, 추가한 시각
- 관계: 하나의 세션 내 운동에 속한다.
- 생명주기: 진행 중인 세션에서 추가·수정·삭제 → 세션 완료 후 수정 불가 → 상위 운동이나 세션이 삭제되면 함께 삭제
- 관련 규칙: BR-002, BR-003, BR-005, BR-007

#### DATA-005 세션 요약
- 설명: 세션의 운동 결과를 한눈에 보여주는 값. 저장할지 매번 계산할지는 설계에서 정한다.
- 관리해야 하는 정보: 운동 시간(종료 시각 − 시작 시각, 중간에 쉰 시간 포함), 운동 수, 총 세트 수, 총 반복 횟수, 총 무게(총 볼륨), 부위별 볼륨·세트 수, 종목별 볼륨·세트 수 (소모 칼로리는 다루지 않는다)
- 관계: 하나의 세션에 대응한다. 날짜별 기록(REQ-WORKOUT-008)은 그날 세션들의 요약으로 만든다.
- 생명주기: 세션 내용에서 산출된다.
- 관련 규칙: BR-008, BR-010, BR-015

#### DATA-006 운동 카테고리(부위)
- 설명: 가슴, 등, 어깨, 하체처럼 종목을 묶는 부위
- 관리해야 하는 정보: 부위명, 부위 이미지, 순서
- 관계: 여러 종목(DATA-002)을 가진다.
- 생명주기: 서비스가 미리 제공한다. 사용자는 만들거나 고칠 수 없다. 가슴, 등, 어깨, 하체 4개다(TODO-014).
- 관련 규칙: BR-009, BR-015, BR-018

## 06. 비즈니스 규칙 / 예외

### 6.1 비즈니스 규칙
여러 문서가 함께 쓰는 규칙이다. 한 문서에서만 쓰는 규칙은 그 문서 6.1에 있다(부록 B).

- **BR-001** 사용자는 자신의 운동 기록만 조회·수정·삭제할 수 있다.
- **BR-002** 완료된 운동 세션에는 운동·세트를 추가·수정·삭제할 수 없다. 종료 시각 등 세션 정보도 고칠 수 없다. 예외: 종목을 지우면 그 종목의 기록은 완료된 세션에서도 지운다(BR-025).
- **BR-004** 운동 세션의 수행 날짜는 시작 시각을 사용자가 있는 지역의 날짜로 바꾼 값이다. 사용자가 직접 정할 수 없으므로 미래 날짜는 생기지 않는다.
- **BR-008** 세션의 종료 시각은 시작 시각보다 앞설 수 없다.
- **BR-009** 세션에는 본인 종목 목록에 있는 종목만 추가할 수 있다. (2026-10-10 변경: 이전에는 "서비스가 제공하는 운동 목록에 있는 운동만 추가할 수 있다. 사용자는 운동 종목을 만들거나 고칠 수 없다.")
- **BR-010** 세션 요약은 기록된 모든 세트로 계산한다. 총 무게는 세트마다 "중량 × 반복 횟수"를 구해 모두 더한 값이다. 운동 수는 세트가 하나 이상 있는 운동만 센다.
- **BR-011** 한 사용자의 진행 중인 세션은 동시에 하나만 있을 수 있다.
- **BR-015** 부위별 볼륨은 그 부위에 속한 종목의 세트마다 "중량 × 반복 횟수"를 구해 모두 더한 값이고, 부위별 세트 수는 그 부위 종목의 세트 수 합이다. 종목별 볼륨·세트 수도 같은 방식으로 계산한다. 계산에 쓰는 세트는 BR-010과 같다.
- **BR-022** 운동 종목 목록은 사용자마다 따로 있다. 사용자는 기본 목록(부록 A)으로 시작하고, 자기 목록만 보고 바꿀 수 있다. 한 사용자가 종목을 바꿔도 다른 사용자의 목록과 기록은 바뀌지 않는다.
