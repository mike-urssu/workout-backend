## 01. 프로젝트 개요

### 1.1 문서 개요
- 정의하는 것: 운동을 마칠 때 "오운완(오늘 운동 완료) 인증" 사진·동영상을 붙이고, 지난 기록에서 다시 보고 기기 앨범에 저장하는 기능이 무엇을 해야 하는지(사용자와 권한, 화면 흐름, 기능, 데이터, 규칙, 예외, 범위).
- 정의하지 않는 것: API 상세 설계, 파일 저장소 선택, DB 스키마, 아키텍처, 기술 스택(→ 설계 문서에서 다룸). 사진·동영상을 고르는 화면이나 재생기의 구현.
- 대상 독자: 백엔드 개발자, 모바일 클라이언트 개발자, 테스트 담당자, 기획자.

### 1.2 서비스 / 기능 개요
사용자는 운동을 마치면서 그날 운동을 인증하는 사진이나 동영상을 붙일 수 있다. 붙인 사진·동영상은 운동 기록 달력에서 그 날짜를 고르면 다시 볼 수 있고, 눌러서 크게 넘겨 볼 수 있으며, 보고 있는 것을 기기 앨범에 저장할 수 있다. 이 기능은 처음에 운동 기록 요구사항의 범위 밖이었지만, 디자인과 앱에 들어가 있어 범위에 넣기로 했다(2026-10-09 사용자 결정).

| 기능 영역 | 설명 | 관련 요구사항 |
|----------|------|--------------|
| 인증 첨부 | 운동 완료 팝업에서 사진·동영상을 골라 세션 완료와 함께 저장한다. | REQ-MEDIA-001 |
| 인증 목록 조회 | 고른 날짜의 운동 기록과 함께 그날의 사진·동영상 목록을 본다. | REQ-MEDIA-002 |
| 인증 크게 보기 | 사진·동영상을 눌러 전체 화면에서 넘겨 보고, 동영상을 재생한다. | REQ-MEDIA-003 |
| 인증 앨범 저장 | 미디어 뷰어에서 보고 있는 사진·동영상 하나를 원본 그대로 기기 앨범에 저장한다. | REQ-MEDIA-004 |

### 1.3 외부 시스템 / 연동
- 사용자가 올린 사진·동영상 파일을 저장하고, 그 사용자에게만 다시 내려줄 수 있어야 한다. (어디에 어떻게 저장할지는 설계 단계에서 정한다)

## 02. 사용자 / 권한

### 2.1 사용자 유형
| 사용자 유형 | 설명 |
|------------|------|
| 비로그인 사용자 | 사진·동영상을 올리거나 볼 수 없다. |
| 일반 사용자 | 로그인한 사용자. 자신의 운동을 완료할 때 사진·동영상을 붙이고, 자신의 것만 본다. |
| 관리자 | 해당 없음 — 관리자 기능은 범위 밖이다(8.1). |

### 2.2 권한 규칙
| 기능 | 비로그인 | 일반 사용자 |
|------|---------|-----------|
| 사진·동영상 첨부 | ✕ | △ 본인 세션 + 완료하는 순간에만 |
| 사진·동영상 목록 조회 / 크게 보기 | ✕ | △ 본인 기록만 |
| 사진·동영상 앨범 저장 | ✕ | △ 본인 기록만 |

- 사진·동영상은 올린 사용자 본인만 볼 수 있다. 다른 사용자는 파일이 있는 위치를 알아도 볼 수 없어야 한다. (BR-001, NFR-SEC-002)
- 사진·동영상은 운동 완료 팝업에서 세션을 완료할 때만 붙일 수 있다. 완료된 기록에 나중에 추가하거나 지울 수 없다. (BR-002)

## 03. 사용자 시나리오 / 화면 흐름

### 3.1 시나리오: 운동을 마치며 인증을 붙인다
```
[운동 완료 팝업] (workout-session WO-002)
        ↓
사용자가 "사진 또는 동영상 추가"를 누르고 앨범에서 고르거나 바로 촬영한다. ── 반복 가능
        ↓
   ├─ 저장하기 → 고른 사진·동영상을 올리고 세션을 완료한다 → [홈 화면]
   │     (올리기에 실패하면 완료하지 않고 팝업에 남는다. 다시 저장하거나 건너뛴다, BR-007)
   ├─ 건너뛰기 → 사진·동영상 없이 세션을 완료한다 → [홈 화면]
   └─ 팝업 닫기 → 세션은 진행 중인 채로 남는다. 저장하기 중 일부를 올린 뒤 닫았다면 올라간 파일은 붙지 않은 채 남았다가 다음 완료·취소·자동 정리 때 지워진다(사용자에게 보이지 않는다)
```

### 3.2 시나리오: 지난 인증을 본다
```
[운동 기록 화면] (workout-history WO-003)
        ↓
사용자가 날짜를 고른다. 그날 인증이 있으면 사진·동영상 목록이 보인다.
        ↓
사용자가 사진·동영상 하나를 누른다.
        ↓
[미디어 뷰어] 누른 것부터 보여주고, 옆으로 넘겨 그날의 다른 사진·동영상을 본다.
        ↓
   ├─ 저장 → 지금 보고 있는 사진·동영상 하나를 기기 앨범에 저장한다 → [미디어 뷰어]에 남는다 ── 반복 가능
   └─ 닫기 → [운동 기록 화면]
```

### 3.3 화면 정의
운동 완료 팝업(WO-002)과 운동 기록 화면(WO-003)은 각각 `workout-session.md`와 `workout-history.md`에 정의되어 있다. 이 문서는 그 화면에 붙는 데이터와 미디어 뷰어만 정의한다.

- WO-002에 붙는 것: "오운완 인증" 영역, 사진·동영상 추가, 고른 개수와 최대 개수(예: 2/5, BR-005). 저장하기는 첨부와 함께 완료하고, 건너뛰기는 첨부 없이 완료한다.
- WO-003에 붙는 것: 고른 날짜에 인증이 있을 때만 "오운완 인증" 목록(사진은 미리보기, 동영상은 첫 장면 미리보기와 재생 표시).

#### MEDIA-001 미디어 뷰어
- 진입 조건:
  - 운동 기록 화면에서 오운완 인증 사진·동영상 하나를 누름
- 사용자 행동:
  - 옆으로 넘겨 이전 / 다음 사진·동영상 보기
  - 동영상 재생
  - 지금 보고 있는 사진·동영상을 기기 앨범에 저장
  - 닫기
- 시스템 동작:
  - 누른 사진·동영상부터 보여준다.
  - 지금 보고 있는 동영상만 재생한다.
  - 저장하면 지금 보고 있는 것 하나의 원본을 받아 기기 앨범에 넣고, 저장했는지 실패했는지 알려준다.
- 화면 데이터:
  - 사진·동영상 (원본을 크게)
  - 지금 위치와 전체 개수 (예: 1 / 3)
- 다음 화면:
  - 운동 기록 (workout-history WO-003)
- 관련 요구사항: REQ-MEDIA-003, REQ-MEDIA-004

### 4.2 기능 상세

#### REQ-MEDIA-001 운동 완료 시 사진·동영상 첨부
- **목적:** 사용자가 운동을 마치면서 그날 운동을 인증하는 사진·동영상을 기록에 남길 수 있어야 한다.
- **사전 조건:**
  - 로그인된 사용자여야 한다.
  - 본인의 진행 중인 세션을 완료하는 중이어야 한다(운동 완료 팝업). 세션 완료 조건은 workout-session REQ-WORKOUT-002를 따른다.
- **사용자 행동:**
  1. 운동 완료 팝업에서 "사진 또는 동영상 추가"를 누른다.
  2. 앨범에서 사진·동영상을 고르거나, 바로 촬영한다. 여러 번 나누어 추가할 수 있다.
  3. 저장하기를 누른다.
- **입력:**
  - 세션 ID
  - 사진·동영상 파일 (하나 이상 5개 이하, 크기·길이·형식은 BR-005, BR-006)
- **처리 규칙:**
  - 고른 순서대로 세션에 붙인다. (BR-003)
  - 사진과 동영상을 섞어 붙일 수 있다. (BR-003)
  - 사진·동영상을 모두 저장해야 세션을 완료한다. 하나라도 저장하지 못하면 세션을 완료하지 않고, 일부만 올라간 파일도 남기지 않는다. 사용자는 다시 저장하거나 건너뛸 수 있다. (BR-007)
  - 건너뛰기를 누르거나 팝업을 닫으면 아무것도 올리지 않는다.
- **결과:**
  - 세션이 완료되고, 사진·동영상이 그 세션에 붙는다.
- **예외:**
  - 로그인하지 않은 경우 인증 오류를 반환한다. (ERR-001)
  - 허용하지 않는 형식의 파일이면 올리지 않고 입력값 오류를 반환한다. (ERR-002)
  - 개수나 크기 상한을 넘으면 올리지 않고 입력값 오류를 반환한다. (ERR-003)
  - 다른 사용자의 세션이면 권한 오류를 반환한다. (ERR-004)
  - 이미 완료된 세션에 붙이려 하면 붙이지 않고 오류를 반환한다. (ERR-005)
  - 올리다가 실패하면 실패를 알린다. (ERR-006)
- **관련 화면:** WO-002

#### REQ-MEDIA-002 날짜별 사진·동영상 목록 조회
- **목적:** 사용자가 지난 운동 기록을 볼 때 그날 붙인 인증을 함께 볼 수 있어야 한다.
- **사전 조건:**
  - 로그인된 사용자여야 한다.
- **사용자 행동:**
  1. 운동 기록 화면의 달력에서 날짜를 고른다.
- **입력:**
  - 날짜 (workout-history REQ-WORKOUT-008과 함께 조회)
- **처리 규칙:**
  - 본인 기록의 사진·동영상만 조회한다. (BR-001)
  - 그날 완료된 세션에 붙은 사진·동영상을 붙인 순서대로 보여준다. 하루에 세션이 여러 개면 합쳐서 세션 순서대로 보여준다(workout-history BR-020).
  - 사진인지 동영상인지 구분해 알려준다.
- **결과:**
  - 그날의 사진·동영상 목록을 받는다.
  - 없으면 빈 목록을 받는다(오류가 아니다). 화면에는 인증 영역을 보여주지 않는다.
- **예외:**
  - 로그인하지 않은 경우 인증 오류를 반환한다. (ERR-001)
- **관련 화면:** WO-003

#### REQ-MEDIA-003 사진·동영상 크게 보기
- **목적:** 사용자가 인증 사진·동영상을 크게 보고 동영상을 재생할 수 있어야 한다.
- **사전 조건:**
  - 로그인된 사용자여야 한다.
  - 본인의 사진·동영상이어야 한다.
- **사용자 행동:**
  1. 운동 기록 화면에서 사진·동영상 하나를 누른다.
  2. 옆으로 넘겨 그날의 다른 사진·동영상을 본다.
  3. 닫는다.
- **입력:**
  - 사진·동영상 식별자
- **처리 규칙:**
  - 본인 것만 내려준다. (BR-001)
  - 누른 것부터 보여주고, 그날 목록 순서대로 넘긴다.
- **결과:**
  - 사진·동영상 원본을 받는다.
- **예외:**
  - 로그인하지 않은 경우 인증 오류를 반환한다. (ERR-001)
  - 다른 사용자의 사진·동영상이면 내려주지 않는다. (ERR-004)
  - 지워졌거나 없는 사진·동영상이면 찾을 수 없음 오류를 반환한다. (ERR-007)
- **관련 화면:** MEDIA-001

#### REQ-MEDIA-004 사진·동영상 앨범에 저장
- **목적:** 사용자가 인증 사진·동영상을 자기 기기의 앨범에 간직할 수 있어야 한다.
- **사전 조건:**
  - 로그인된 사용자여야 한다.
  - 본인의 사진·동영상이어야 한다.
  - 미디어 뷰어(MEDIA-001)에서 그 사진·동영상을 보고 있어야 한다.
  - 기기 앨범에 저장할 수 있도록 사용자가 허락해야 한다.
- **사용자 행동:**
  1. 미디어 뷰어에서 저장을 누른다.
  2. (처음이면) 기기 앨범 접근을 허락한다.
- **입력:**
  - 지금 보고 있는 사진·동영상 식별자
- **처리 규칙:**
  - 본인 것만 내려준다. (BR-001)
  - 한 번에 하나, 지금 보고 있는 것만 저장한다. (BR-008)
  - 미리보기가 아니라 올린 원본을 형식 그대로 저장한다. 사진은 사진으로, 동영상은 동영상으로 앨범에 들어간다. (BR-008)
  - 받는 동안 진행 상황을 보여줄 수 있어야 한다. (NFR-PERF-001)
  - 같은 것을 다시 저장하면 앨범에 하나 더 들어간다(이미 저장했는지 기억하지 않는다).
- **결과:**
  - 사진·동영상이 기기 앨범에 저장되고, 저장했다고 알려준다. 미디어 뷰어에 그대로 남는다.
- **예외:**
  - 로그인하지 않은 경우 인증 오류를 반환한다. (ERR-001)
  - 다른 사용자의 사진·동영상이면 내려주지 않는다. (ERR-004)
  - 지워졌거나 없는 사진·동영상이면 찾을 수 없음 오류를 반환한다. (ERR-007)
  - 사용자가 앨범 접근을 허락하지 않으면 저장하지 않고 허락이 필요하다고 알려준다. (ERR-008)
  - 받다가 실패하거나 앨범에 넣지 못하면 실패를 알리고, 다시 저장할 수 있다. (ERR-009)
- **관련 화면:** MEDIA-001

## 05. 데이터 요구사항

#### DATA-001 오운완 인증 사진·동영상
- 설명: 사용자가 운동 세션을 완료하며 붙인 사진이나 동영상 하나
- 관리해야 하는 정보: 소속 세션, 종류(사진 / 동영상), 파일, 세션 안에서의 순서, 올린 시각
- 관계: 하나의 운동 세션(workout-common DATA-001)에 속한다. 세션 하나에 0개 이상.
- 생명주기: 세션을 완료할 때 생성 → 이후 추가·수정·삭제 불가(BR-002). 앨범에 저장해도 바뀌지 않는다 → 세션이 삭제되면 파일까지 함께 완전히 삭제(BR-004) → 계정이 삭제되면 함께 삭제(auth BR-012)
- 관련 규칙: BR-001 ~ BR-004

## 06. 비즈니스 규칙 / 예외

### 6.1 비즈니스 규칙
- **BR-001** 사진·동영상은 올린 사용자 본인만 조회할 수 있다.
- **BR-002** 사진·동영상은 운동을 완료할 때(운동 완료 팝업에서 저장하기) 고른 것만 그 세션에 붙는다. 저장하기를 누르면 고른 파일을 진행 중인 세션에 먼저 올려 두고, 완료하면서 붙인다. 완료된 세션에는 더 올리거나 붙일 수 없고, 붙인 뒤에는 따로 지울 수 없다(세션을 지우면 함께 지워진다, BR-004).
- **BR-003** 한 세션에 사진과 동영상을 섞어 여러 개 붙일 수 있고, 붙인 순서를 유지한다.
- **BR-004** 세션을 삭제하면(사용자 삭제, 방치된 세션 자동 삭제, 계정 삭제) 그 세션의 사진·동영상 파일도 남김없이 삭제한다. 운동 기록을 실제 삭제하기로 한 결정(workout-common TODO-001)과 같다.
- **BR-005** 한 세션에 사진·동영상을 5개까지 붙일 수 있다(2026-10-11 10개에서 바꿈, TODO-001). 사진 파일은 20MB 이하, 동영상 파일은 100MB 이하이고 길이는 1분 이하다.
- **BR-006** 사진은 JPEG, PNG, HEIC, 동영상은 MP4, MOV 형식만 받는다.
- **BR-007** 저장하기에서 사진·동영상을 하나라도 저장하지 못하면 세션을 완료하지 않고, 일부만 올라간 파일도 남기지 않는다. 기록한 세트와 고른 사진·동영상을 잃지 않고 다시 시도할 수 있게 하기 위해서다.
- **BR-008** 기기 앨범에는 미디어 뷰어에서 지금 보고 있는 사진·동영상 하나를, 올린 원본 그대로 저장한다.

  - 날짜별 기록에서 사진·동영상 목록 보기 (동영상은 첫 장면 미리보기)

  - 미디어 뷰어에서 지금 보고 있는 사진·동영상 하나를 기기 앨범에 저장 (2026-10-11 사용자 결정)
- **제외:** (아래 기능은 요청이 있기 전까지 만들지 않는다)
  - 완료된 기록에 사진·동영상을 나중에 추가하거나 지우기 (TODO-005 결정)

  - 사진·동영상에 글이나 태그 달기
  - 다른 사용자에게 공유, 공개 피드, SNS로 내보내기 (기기 앨범 저장은 포함, REQ-MEDIA-004)
  - 그날 또는 여러 날의 사진·동영상을 한꺼번에 저장하기, 운동 기록 화면 목록에서 바로 저장하기
  - 앨범에 저장할 때 형식 바꾸기, 크기 줄이기, 워터마크 넣기
  - 사진·동영상만 모아 보는 갤러리 화면
  - 진행 중인 운동 도중에 사진·동영상 올리기
  - 관리자 검토·신고 기능

### 8.2 제약사항
- `workout-common.md` 8.1(분리 전 `workout-record.md`)이 "운동 사진/영상 첨부, 갤러리"를 제외했으나, 2026-10-09 사용자 결정으로 이 문서에서 범위에 넣었다.

- 개수 상한을 10개에서 5개로 줄이기 전에 6개 이상 붙여 완료한 기록은 그대로 두고 모두 보여준다. 완료된 기록은 고칠 수 없다(BR-002).
